# How SmartClipBoard works

```
 ┌────────────── your Mac (your user session) ──────────────┐
 │ launchd ──(at login)──▶ SmartClipBoard.app                │
 │                           │                               │
 │   NSPasteboard ◀─ every 0.5 s: "has changeCount moved?"   │
 │        │  yes → read the clipboard once                   │
 │        ▼                                                  │
 │   ClipboardMonitor ── skip passwords and our own copies   │
 │        │  files       → photo / GIF / video               │
 │        │  image data  → saved to the temp folder (PNG/GIF)│
 │        │  text        → word chip                         │
 │        ▼                                                  │
 │   ClipboardStore (in memory: 30 words, 20 media)          │
 │        ▼                                                  │
 │   IslandController: borderless panel over the notch       │
 │     hover → window grows, SwiftUI spring animation        │
 │     click → write the item back to the clipboard          │
 │     drag  → AppKit drag session (text or file URL)        │
 └───────────────────────────────────────────────────────────┘
```

## 1. Watching the clipboard

macOS doesn't notify apps when the clipboard changes. Instead, a timer compares one number, the
pasteboard's `changeCount`, every 0.5 s. The timer has a 0.25 s tolerance, so macOS can group its
wake-ups with other work.

The app reads the clipboard's contents only when that number changes. Checking the number alone
doesn't count as reading the clipboard, so it never triggers macOS's paste-privacy prompt.

## 2. Sorting what you copied

The first rule that matches wins:

1. **Files copied in Finder.**
   - `.gif` files become GIF tiles.
   - Other images become photo tiles.
   - Movies become video tiles.
   - Other file types are ignored.
   - The app keeps a reference to the original file; it doesn't make a copy.
2. **Image data**, such as a ⌃⇧⌘4 screenshot or "Copy Image" in a browser.
   - It is saved as a PNG or GIF in the app's private temp folder, so it can be dragged and
     pasted as a real file.
   - If the copy also contains real text, the text wins. Word, Excel and Keynote add a picture of
     the selection next to the text, and that picture is not what you meant to copy.
3. **Text** becomes a word chip.
   - If you copy the same text again, its chip moves to the front instead of appearing twice.

Entries marked `org.nspasteboard.ConcealedType`, `TransientType` or `AutoGeneratedType` are
skipped. Password managers use these markers. Copies made while Passwords or Keychain Access is
the frontmost app are skipped as well.

## 3. The island

- **Where it sits.** The app finds the notch from `NSScreen.safeAreaInsets` and
  `auxiliaryTopLeftArea` / `auxiliaryTopRightArea`. It places a borderless, transparent panel
  above the menu bar, sized exactly to the notch. When collapsed, the panel is black on black, so
  you can't see it.
- **Without a notch** (lid closed, or a Mac without a notch), the same panel becomes an invisible
  hover zone at the top centre of the main screen.
- **Hover detection.** It is event-driven, using an `NSTrackingArea`. Nothing polls the mouse, and
  no Accessibility permission is needed.
  - After you hover for 0.12 s, the window grows. A SwiftUI spring then animates the shape out of
    the notch.
  - About 0.25 s after the pointer leaves, it closes.
  - While a drag is in progress, it stays open.
- **Keyboard focus.** The panel is a non-activating panel that can never become the key window.
  The app you're working in keeps keyboard focus, so ⌘V after a click goes there.

## 4. Copy and drag

- **Clicking text** puts the original text back on the clipboard as plain text.
- **Clicking a photo** puts the file reference plus the file's own image data (PNG, JPEG or HEIC)
  on the clipboard. That covers both Finder and image-aware apps. A TIFF version is created only if
  the app you paste into asks for it.
- **Dragging** hands macOS the text or the file URL with a "copy" operation. Finder, the Desktop,
  Mail, Messages, Telegram, browsers and editors all accept that.

## CPU and memory

Measured on a MacBook Air M2 (8 GB, macOS 26.2) with `top` and `ps`:

| State | CPU | Memory |
|---|---|---|
| Idle, collapsed | 0.0–0.1 % of one core, 0 idle wake-ups | about 11 MB private (about 39 MB resident, which includes shared system frameworks) |
| Opening or closing | a short burst for about 0.4 s; Core Animation composites on the GPU | unchanged |
| A new copy | under 5 ms for text; about 30–100 ms once for a large screenshot, off the main thread | about +250 KB per media thumbnail (256 px), at most 20 |

- **Full history:** expect about 20 MB of private memory, roughly 0.25 % of 8 GB.
- **Network:** the app makes no network connections.
- **Disk:** the app itself is under 1 MB.

To check it on your own Mac:

```bash
top -pid $(pgrep -x SmartClipBoard) -l 3 -stats cpu,mem,idlew
```

## Everything it touches on your Mac

| What | Where |
|---|---|
| App | `~/Applications/SmartClipBoard.app`, your user only, no admin password needed |
| Auto-start | `~/Library/LaunchAgents/com.vladimirbelaev.smartclipboard.plist`. `launchd` starts the app at login and restarts it after a crash, but not after you quit it. |
| Temporary images | `$(getconf DARWIN_USER_TEMP_DIR)SmartClipBoard/`, your private `/var/folders/…/T/` folder. Files are deleted when an item leaves the history, and the folder is cleared when the app quits and when it starts. |
| On screen | A window above the menu bar, on every Space and over full-screen apps. It isn't in the Dock, ⌘Tab or Mission Control (`LSUIElement`). |

Nothing else is written. The app has no preferences file and no database, and makes no network
calls.

## Source layout

```
Package.swift                       Swift package, macOS 14+
Resources/Info.plist                agent app (no Dock icon), bundle id
Sources/SmartClipBoard/
  main.swift                        startup, single-instance guard
  ClipItem.swift                    history item model
  ClipboardMonitor.swift            clipboard polling, privacy filter, sorting
  ClipboardStore.swift              in-memory history, copy-back, thumbnails, temp files
  IslandController.swift            notch geometry, panel, hover, expand/collapse
  Views/IslandView.swift            island shape, header, sections
  Views/WordChip.swift              word chip + wrapping layout
  Views/MediaTile.swift             thumbnail tile + type badge
  Views/DragSource.swift            click, drag and right-click handling
scripts/
  config.sh                         shared names and paths
  build.sh                          build the .app with the Command Line Tools
  install.sh                        build, install, start, auto-start
  autostart.sh                      turn auto-start on or off
  uninstall.sh                      remove everything
```
